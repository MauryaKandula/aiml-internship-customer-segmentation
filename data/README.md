# Dataset attribution

The CSV is the UCI Machine Learning Repository's Wholesale customers dataset.

- Creator: Margarida Cardoso
- Citation: Cardoso, M. (2013). Wholesale customers [Dataset]. UCI Machine Learning Repository.
- DOI: https://doi.org/10.24432/C5030X
- Dataset page: https://archive.ics.uci.edu/dataset/292/wholesale%2Bcustomers
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)

The data records annual spending in monetary units for six product categories, plus channel and region. The original spelling Delicassen is retained.
